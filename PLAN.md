1. **Где живёт проект.** Репозиторий `Meewe123/concepts`, ветка `main` (на компьютере — `D:\concepts`). Демо Black Star в облаке недоступно, поэтому скрипты проверки шрифтов, типограф и скриншоты пишу заново (`scripts/`, `core/typograf.ts`).

Адрес — `https://concepts.<поддомен>.workers.dev`; поддомен вписывается в `site.config.ts`, оттуда берутся ссылки, `link.txt` и `og:image`.
   - Сеть контейнера: npm и Google Fonts открыты; Cloudflare (`api.cloudflare.com`, `*.workers.dev`, `static.cloudflareinsights.com`), Яндекс и Google закрыты. Живой сайт отсюда не открыть — проверяю локально через `wrangler dev`, на живой ссылке проверяете вы. Если добавить `workers.dev` в разрешённые домены окружения, проверю сам.
   - Данные лидов беру из таблицы в ТЗ как есть: перепроверить карточки Яндекса отсюда не могу.
3. **Next.js и «JS только для островков».** Решено в Фазе 1: после `next build` скрипт `strip-runtime` убирает рантайм Next/React со всех страниц, интерактив — островки на чистом TypeScript (banquet — 3,6 КБ). Lighthouse mobile — 99–100.

## 1. Стек

- Next.js 16 (App Router, `output: 'export'`), React 19, TypeScript strict. Версию TS выберу ту, которую официально поддерживает Next 16.

- Деплой — Cloudflare Workers (static assets): папка `out/`, `wrangler.jsonc`, `_headers`, `robots.txt`.

### Ключевые решения

- **Концепт = ниша × направление × лид.** Ниша задаёт секции и сигнатуру, направление — внешний вид, лид — данные и тексты. Чтобы пять банкетных залов были пятью разными мирами, а не одним шаблоном в пяти цветах, у каждого направления свой Hero, свой мотив, своя «кожа» сигнатуры и свои варианты композиции секций. Общее — только логика и структура данных.
- **Служебные страницы не попадают в публичную сборку.** `/internal` и `/og/[slug]` — файлы `*.dev.tsx`, их подключает `pageExtensions` только в dev и в режиме инструментов. В `out/` их физически нет.
- **Шрифты.** На `/c/<slug>` грузятся и предзагружаются только шрифты направления этого лида; проверю это отдельно, потому что все направления живут в одном маршруте.
- **Языки.** RU — основная версия по адресу `/c/<slug>`, UZ — по `/c/<slug>/uz`. Переключатель языка — обычная ссылка, без JS. Банкетные залы — RU + UZ, остальные ниши — RU, UZ по флагу в конфиге.
- **Адреса.** slug = латиница названия + 4 символа из алфавита без похожих знаков (`abcdefghjkmnpqrstuvwxyz23456789`) — около 920 тыс. комбинаций на одно название. Нигде нет списка концептов: ни sitemap, ни ссылок со страницы студии.
- **Честность.** Внизу плашка «Демо-концепт для <Компания>. Не официальный сайт. Цены и данные примерные». `noindex, nofollow` трижды: `robots.txt`, `<meta>`, заголовок `X-Robots-Tag`. В `robots.txt` открыт доступ только ботам превью ссылок (Telegram, Instagram/Facebook, WhatsApp), иначе в мессенджере не будет карточки. Неизвестные данные несут `example: true`, и `check.ts` не пропустит сборку, если пример показан без пометки.
- **Аналитика.** Cloudflare Web Analytics подключаю своим сниппетом (`core/analytics.tsx`, токен — в `site.config.ts`): только так `?me=1` может его отключить. `?me=1` ставит флаг в `localStorage`, и сниппет больше не вставляется; `?me=0` снимает флаг; параметр сразу убирается из адресной строки, чтобы не уйти лиду в скопированной ссылке. Бот превью Telegram не выполняет JS, поэтому в просмотры не попадает.
- **Карта.** Статичная SVG-схема: улица, 2–3 ориентира рядом (метро, магистраль, канал), точка адреса. Ориентиры задаются в конфиге лида. Схема стилизована под направление.
- **Форма.** Демо: показывает «Заявка отправлена» и ничего никуда не отправляет. В продакшне — код воркера (`main` в `wrangler.jsonc`) → Telegram-бот клиента.

## 4. Направления: правки к библиотеке

В трёх нишах у двух направлений совпадал главный шрифт, а это нарушает правило «никаких похожих концептов внутри ниши». Предлагаю:

| Направление | Было | Стало | Почему |
|---|---|---|---|
| `showroom-chrome` (Urus) | Tektur + Onest | **Unbounded 200/700 + Onest** | Tektur уже у `workshop-concrete` (Brookland). Широкий Unbounded тонкого начертания — ощущение шоурума |
| `spa-whisper` (Women secret) | Cormorant Garamond + Commissioner | **Spectral 200/300 italic + Commissioner** | Cormorant уже у `glossy-editorial` (Expert Beauty). Лёгкий Spectral — тот самый «шёпот» |
| `night-shift` (Chilanzar) | IBM Plex Sans | **Commissioner + Source Code Pro (часы)** | IBM Plex уже у `clinical-silk` (Denta) |

Остальная библиотека — как в ТЗ. Внутри каждой ниши после правок разные палитра, шрифтовая пара, композиция, фактура и характер движения.
